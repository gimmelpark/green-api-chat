# GREEN-API Telegram Chat

Тестовое задание на позицию фронтенд разработчика React в GREEN-API.

Простой чат для отправки и получения текстовых сообщений Telegram через [GREEN-API](https://green-api.com).

Стек: React, TypeScript, Vite, Tailwind CSS, Zustand.

## Запуск

```bash
npm install
npm run dev
```

Приложение будет доступно на http://localhost:5173/green-api-chat.

Сборка: `npm run build`, посмотреть собранную версию: `npm run preview`.

## Как пользоваться

1. Создать и авторизовать Telegram инстанс в [консоли GREEN-API](https://console.green-api.com).
2. Войти с apiUrl, idInstance и apiTokenInstance из консоли.
3. Добавить чат по номеру телефона или @username.
4. Писать сообщения, ответы появятся в чате.

Сообщения принимаются через HTTP API, поэтому в настройках инстанса webhookUrl должен быть пустым, а уведомления о входящих, исходящих сообщениях и статусах включены.

## Ограничения

- Только текстовые сообщения, остальные типы показываются заглушкой.
- История не загружается, сообщения хранятся в памяти до перезагрузки страницы.
- Сообщения из чатов, которых нет в списке, пропускаются.
- Данные входа и список чатов хранятся в localStorage.
